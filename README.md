# Nivoseas Lighting

Premium architectural and decorative lighting solutions based in Sector 104, Noida, UP.

## Tech Stack
- **Framework:** [Next.js 16](https://nextjs.org/) (App Router & Turbopack)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Typography:** Geist, Geist Mono & Playfair Display
- **Icons:** React Icons

## Getting Started

First, install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

## Key Features
- **Architectural Navigation Header:** Full mega-menu with interactive product categories, solutions, and lighting design tools.
- **Peak Design Design Tokens:** Mapped CSS custom properties and Tailwind v4 theme variables.
- **Responsive Experience:** Full mobile slide-over drawer with collapsible product hierarchies.
- **Showroom & Contact Details:** Integrated WhatsApp studio helpline (+91-9990179666) and Sector 104 Noida store location.
